# Global Example Skill

This is a template verification that global skills are working.

## Overview
Global skills are stored in `~/.gemini/antigravity/skills/` and are accessible across all your workspaces.

## Usage
The agent will automatically index skills found in the global directory.

## Instructions
1. This skill is available globally.
2. Use it for general-purpose workflows like "git-best-practices" or "code-review-standards".
